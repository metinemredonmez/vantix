# Ekran Haritası

## Kullanıcı (web + mobile)
- Onboarding: hesap bağlama (kurum seçimi), risk profili anketi
- Ana: Portfolio | Trade sekmeleri, ortak üst bar (bakiye, P/L, bildirim)
- Portfolio: sağlık skoru, exposure (look-through), Portfolio Doctor, AI Builder (before/after), stress test, rebalancing önerileri, shadow portfolio, "neden?" paneli
- Trade: watchlist, chart (entry/TP/SL sürüklenebilir), DOM/ladder (tek tık, drag = cancel/replace), order ticket (simple/advanced), chain builder (ağaç görünümü), blotter (orders/positions/trades), order templates
- Hesap: pozisyonlar, işlem geçmişi, raporlar, ayarlar
- Mobile öncelik: pozisyon/emir takibi, hızlı SL/TP ekleme, portföy özeti, push

## Admin
- Tenants & white-label, broker adapters, risk limits, fund universe & scoring weights, users & suitability, audit & event replay, system health
